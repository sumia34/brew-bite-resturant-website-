# 🍽️ Brew Bite — Restaurant Website

A modern, responsive restaurant website designed to showcase a restaurant's atmosphere, menu, food gallery, and contact information in an attractive, user-friendly layout.

🔗 **Live Demo:** [Visit Brew Bite](https://sumia34.github.io/brew-bite-resturant-website-/)

## 📸 About the Project

Brew Bite is a restaurant website project focused on clean design, responsive layouts, and a smooth browsing experience across desktop, tablet, and mobile devices.

The goal is to present restaurant information in an engaging way and make it easy for visitors to explore the website.

## ✨ Features

- **Responsive Design** — adapts to different screen sizes.
- **Hero Section** — introduces the restaurant with a prominent banner and action buttons.
- **Menu Section** — presents restaurant menu content.
- **Food Gallery** — showcases food and restaurant imagery.
- **Contact Section** — gives visitors access to restaurant contact information.
- **Interactive Buttons** — provides clickable calls to action.
- **Clean Layout** — organized sections for easier navigation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

You can view the live website using the link above or run the project locally.

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/sumia34/brew-bite-resturant-website-.git
   ```

2. Open the project folder:

   ```bash
   cd brew-bite-resturant-website-
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use the Live Server extension if you have it installed.
